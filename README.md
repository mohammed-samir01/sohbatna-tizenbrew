# Sohbatna — TizenBrew module (Samsung Tizen TVs)

**Sohbatna is a player only. It provides no channels or content** — you sign in with the subscription details from your own provider.

This repository holds the built web app for Samsung (Tizen) TVs, packaged as a [TizenBrew](https://github.com/reisxd/TizenBrew) *app module*.
Status: **experimental** — not yet confirmed on a real Samsung TV. Report problems at https://sohbatna.com/contact

## Install (Arabic steps with pictures: https://sohbatna.com/guides/samsung)

1. Install TizenBrew on the TV with **TizenBrew Installer** on a computer (Windows: https://github.com/reisxd/TizenBrewInstaller/releases/latest/download/TizenBrewInstaller-win-x64.exe)
2. On the TV open TizenBrew → module manager → add module, choose **GitHub** and enter:

   ```
   mohammed-samir01/sohbatna-tizenbrew
   ```
   (full name: `gh/mohammed-samir01/sohbatna-tizenbrew`)
3. Open **صحبتنا** from TizenBrew.
